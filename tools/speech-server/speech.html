Speech server

Text-to-speech, your own (cloned) voices and speech-to-text for the llama.cpp web UI. Everything runs on this computer; the page that uses it sends only the text to read or the clip you recorded.

Use it from the llama.cpp web UI

  1. Open the web UI (llama-server, usually port 8080) → Settings → Voice. It finds this server on the same host, port 8179 (or put this server's URL in the field).
  2. Pick an engine and a voice. llama.cpp (Qwen3-TTS) needs one download (Models → Download, 2.5 GB) and clones voices.
  3. Your voices → Record: read the passage on screen for ~10 s, name it, save. Nothing is trained; the voice is usable at once.
  4. Every reply gets a 🔊 Read aloud button; Settings → Voice can read replies automatically. The 🎤 button dictates into the message box (Settings → Microphone).
